# Space Mining

A Gymnasium-compatible environment for training reinforcement learning agents to mine resources from asteroids and return them to a mothership while managing energy and avoiding obstacles.

## Quick Start

1. Install the package:
   ```bash
   pip install .
   ```

2. Run an example:
   ```bash
   python example.py
   ```

## Project Structure

- `space_mining/envs/`: Gymnasium environment implementations
- `space_mining/agents/`: PPO training and inference logic
- `space_mining/scripts/`: Utility scripts for visualization and rendering
- `example.py`: A short example to register and run the environment
- `docs/`: Documentation
- `tests/`: Unit tests
